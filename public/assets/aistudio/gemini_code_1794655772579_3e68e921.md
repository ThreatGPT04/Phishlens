# Product Specification: PhishLens (Arcade Triage Edition)

## 1. Overview
**PhishLens** is a static, AI-powered cybersecurity triage application designed to help analysts and end users safely inspect suspicious emails, URLs, redirection chains, and ClickFix ("copy-paste this command") lures. Instead of executing payloads or visiting live links, the app uses Gemini to perform static inspection, deobfuscate commands, extract defanged Indicators of Compromise (IOCs), and issue a clear **Red Flag (Malicious)**, **Amber Flag (Suspicious)**, or **Green Flag (Likely Safe)** verdict.

## 2. Core Security Guardrails
* **Zero Execution / Zero Fetching:** The frontend and backend must **never** make HTTP requests to pasted URLs, follow live redirects, render unescaped HTML from pasted emails, or execute pasted shell commands. All inspection is purely lexical and semantic via LLM inference.
* **Automatic Defanging:** All extracted domains, URLs, and IPs must be displayed in defanged format (`hxxp://`, `evil[.]example[.]com`) to prevent accidental clicks.
* **Server-Side API Key Isolation:** In production/full-stack deployments, Gemini API calls run through a server-side endpoint (`POST /api/analyze`) so the API key is never exposed in client-side bundles.

## 3. User Flow & Features
1. **Artifact Input Console:**
   * Single large multi-line input field accepting raw email headers + body, standalone URLs (including open-redirect wrappers), or ClickFix terminal lures (`Win+R`, `mshta`, PowerShell, `curl | bash`).
   * **"Load Sample" Selector:** Pre-loaded synthetic test cases:
     1. *ClickFix CAPTCHA Lure* (Base64-encoded PowerShell payload pointing to `example.invalid`).
     2. *Spoofed M365 Password Expiry Email* (failing SPF/DKIM + lookalike login link).
     3. *OAuth Open-Redirect URL* (legitimate domain wrapping a malicious destination URL).
2. **AI Triage Engine (Structured JSON Output):**
   * Gemini analyzes the artifact and returns a strict JSON payload containing:
     * `verdict`: `"Malicious"` (Red Flag) | `"Suspicious"` (Amber Flag) | `"Likely Safe"` (Green Flag)
     * `risk_score`: Integer `0–100`
     * `attack_type`: Classification (e.g., *ClickFix*, *Credential Phishing*, *Open Redirect*, *BEC*)
     * `redirect_analysis`: Breakdown of hidden destination URLs, URL shorteners, or encoded query parameters
     * `red_flags`: Array of `{ indicator, why_it_matters }`
     * `decoded_command`: Step-by-step plain-English breakdown of any shell command + obfuscation techniques spotted
     * `iocs`: Defanged lists of `domains`, `urls`, `ips`, `files`, and `commands`
     * `mitre_attack`: Array of `{ technique_id, name }`
     * `recommended_actions`: Step-by-step containment actions
     * `user_awareness_tip`: Single-sentence takeaway for end users
3. **Arcade Triage Dashboard:**
   * **Verdict Banner & Risk Meter:** High-contrast Red/Amber/Green status badge paired with an animated `0–100` arcade threat meter.
   * **URL & Redirect Inspector Card:** Highlights hidden destination targets behind wrappers or tracking links.
   * **Command Decoder Card:** Displays deobfuscated command behavior (visible when a command is detected).
   * **Red Flags & MITRE ATT&CK Cards:** Scannable breakdown of indicators and mapped ATT&CK technique badges.
   * **IOC Vault:** Defanged indicators with a one-click **"Copy All IOCs"** button.
   * **Incident Ticket Generator:** Modal or expandable drawer generating a formatted Markdown/plain-text SOC ticket with a one-click copy button.

## 4. Visual & Typography Direction
* **Theme:** Retro-Modern Arcade HUD — deep obsidian/indigo cabinet background (`#090A10`), dark slate panel cards (`#121524`), crisp `1px–2px` pixel-inspired borders, subtle CRT scanline texture overlay, and neon status accents (Arcade Crimson `#FF2A5F` for Red Flag, Cyber Amber `#FFB800` for Suspicious, Phosphor Green `#00E676` for Green Flag, and Electric Cyan `#00E5FF` for interactive controls).
* **Typography:** **Google Sans** (with `JetBrains Mono` fallback for raw payloads, decoded commands, and defanged IOCs).
