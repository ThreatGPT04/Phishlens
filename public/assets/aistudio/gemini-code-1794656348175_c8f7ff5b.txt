1. ZERO EXECUTION / ZERO FETCHING: The app must NEVER fetch, curl, render as HTML, or execute anything pasted by the user. All pasted inputs and AI outputs must be rendered strictly as escaped plain text (`textContent` / safe JSX text interpolation).
2. SERVER-SIDE GEMINI INTEGRATION: Keep the Gemini API key strictly on the server side (e.g., via a backend `/api/analyze` route using `process.env.GEMINI_API_KEY` and `@google/genai`). Never expose the API key in frontend client code.

Functional Requirements:
1. Input & Synthetic Samples:

2. Gemini Analysis Endpoint (`POST /api/analyze`):
   - Use Gemini (`gemini-2.5-flash`) with `responseMimeType: "application/json"` and a strict `responseSchema` enforcing these exact fields:

     - `recommended_actions`: array of strings
